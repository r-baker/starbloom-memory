## What this repository actually contains

Original code (C#/Harmony patches) and original data files (JSON stat
conversions, mod manifests) that modify a legally-owned copy of
*BattleTech* to add Gundam Universal Century–themed units, equipment, and
mechanics. It requires the base game to function and does not include or
redistribute any of the base game's own copyrighted files.

Unit stats, weapon values, and equipment mechanics here are **original
mechanical interpretations** — translations of Gundam UC concepts into
BattleTech's own rules, not transcriptions of any official tabletop or
video game rulebook.
