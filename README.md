# GundamUC-Units

A Gundam Universal Century (One Year War era) total-conversion mod for
*BattleTech* (Harebrained Schemes, 2018), built on
[ModTek](https://github.com/BattletechModders/ModTek).

**Unofficial fan project — see [`NOTICE.md`](NOTICE.md) for the full
disclaimer.** Not affiliated with Harebrained Schemes/Paradox or with
Sunrise/Sotsu/Bandai Namco.

## What's here

- **Ten Universal Century units**, stat-converted into BattleTech's own
  rules: Guntank (RTX-65), Guncannon First Type (RCX-76-02), Prototype
  Gundam (RX-78-1), Zaku I & II, GM, Gouf, Dom, Ground Type Gundam, and
  the Ez-8.
- **A Career-mode campaign start**: the player begins with a Guntank/
  Guncannon squadron on the eve of the One Year War's outbreak (UC 0079),
  with the Prototype Gundam delivered shortly after via a scripted
  flashpoint event rather than being purchasable from the start.
- **A hand-weapon system** for units with humanoid hands: swappable
  hand-carried weapons (rifle, backup cannon, melee) route through a
  dedicated "Handheld" MechLab panel, with real turn-based combat rules —
  only one hand-weapon fireable at a time, melee auto-claims the hand when
  used, and losing both arms disables all of them.
- Supporting mechanics: an armor-weight-efficiency item (Luna Titanium),
  tiered reactor/engine upgrades, and per-unit weight-balancing against
  each chassis's real tonnage cap.

## Installing

Requires a legally-owned copy of *BattleTech* (2018) and
[ModTek](https://github.com/BattletechModders/ModTek) installed first.
Drop this repository's contents into your `Mods/GundamUC-Units/` folder.
